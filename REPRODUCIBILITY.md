# Reproducibility Guide

This artifact is the runnable code release for the paper "Conservation Laws for
Diffusion Models". It tracks source code, experiment configs, launch scripts,
and tests. It does not track downloaded datasets, checkpoints, W&B folders,
Slurm logs, or generated result directories.

Run commands from the repository root unless stated otherwise.

## Artifact Policy

- Synthetic data is generated by the configs at run time.
- `text8` is bootstrapped with `scripts/download_lm_datasets.py`.
- CIFAR-10 RGB8 image-token data is created with
  `scripts/prepare_cifar10_rgb8_tokens.py`.
- Large checkpoints and raw generated outputs should remain outside git under
  `results/`, `data/`, or an external archive.
- Use `logging.enabled=false` for local runs without W&B initialization. Use
  `logging.mode=online` only when intentionally sending a run to Weights &
  Biases.

## Environment Setup

```bash
conda create -n gexit python=3.11 -y
conda activate gexit
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

If your machine needs a CUDA-specific PyTorch build, install the matching
`torch` package first and then install the remaining requirements. For
non-interactive jobs, prefer `conda run -n gexit ...` instead of activating the
environment in the shell.

## Data Setup

Synthetic experiments require no external dataset download.

Bootstrap `text8`:

```bash
python scripts/download_lm_datasets.py --dataset text8
```

Validate or refresh `text8`:

```bash
python scripts/download_lm_datasets.py --dataset text8 --verify-only
python scripts/download_lm_datasets.py --dataset text8 --force
```

Expected `text8` files:

- `data/lm/text8/text8`
- `data/lm/text8/train.bin`
- `data/lm/text8/val.bin`
- `data/lm/text8/test.bin`

Prepare CIFAR-10 RGB8 tokens:

```bash
python scripts/prepare_cifar10_rgb8_tokens.py --output-dir data/img/cifar10_rgb8_tokens
```

Expected CIFAR-10 files:

- `data/img/cifar10_rgb8_tokens/train_tokens.pt`
- `data/img/cifar10_rgb8_tokens/val_tokens.pt`
- `data/img/cifar10_rgb8_tokens/test_tokens.pt`
- `data/img/cifar10_rgb8_tokens/tokenizer_metadata.json`

## Reproducibility Manifest

List every paper reproduction target, including matrix-expanded Markov alphabet
sizes:

```bash
python scripts/run_repro_manifest.py --profile paper --group smoke --list
```

Run the short smoke profile. The smoke profile keeps the paper model/data
hyperparameters and shortens optimization and evaluation work:

```bash
python scripts/run_repro_manifest.py --profile smoke --group smoke --run
```

On Slurm/H200 systems, this launcher runs the same smoke manifest; override
account, partition, and GPU directives at submission time when needed:

```bash
sbatch experiments/repro/run_smoke_h200.sbatch
```

## Paper Experiment Map

| Paper area | Configs | Entry points |
| --- | --- | --- |
| Synthetic Markov scaling and QSC baseline | `configs/experiments/markov_scaling/*`, `configs/experiments/markov_channel_k128/qsc.yaml` | `scripts/train_causal_ce.py`, `scripts/train_exit.py`, `scripts/train_immse.py`, `scripts/train_bsc.py` |
| Markov channel comparison | `configs/experiments/markov_channel_k128/*` | `scripts/train_exit.py`, `scripts/train_bsc.py`, `scripts/train_immse.py` |
| Language modeling | `configs/experiments/text8/paper_*` | `scripts/train_lm_causal_ce.py`, `scripts/train_lm_exit.py`, `scripts/train_lm_immse.py`, `scripts/train_lm_qsc.py` |
| CIFAR-10 RGB8 UNet image tokens | `configs/experiments/cifar10_rgb8_unet/paper_*` | `scripts/train_img_exit.py`, `scripts/train_img_immse.py`, `scripts/train_img_qsc.py` |
| LM conservation-law evaluation | `configs/experiments/text8/*` and saved LM checkpoints | `scripts/eval_lm_conservation.py`, `scripts/eval_lm_checkpoints.py` |
| CIFAR-10 image evaluation suite | saved image checkpoints or W&B run ids | `scripts/eval_cifar_suite.py`, `experiments/eval_cifar_suite_h200_hp.sbatch` |
| Server-scale evaluation launchers | Slurm cluster or multi-GPU VM run paths and saved checkpoints | `experiments/server/slurm/*`, `experiments/server/multigpu/*` |

All top-level paper presets use seed `2026` unless explicitly overridden.
Publication commands use the explicit `paper_*` Hydra configs where available.
Neighboring configs without the `paper_` prefix are lower-memory or development
presets and are not the canonical paper commands.

For `text8`, the `paper_*` training configs use bounded periodic evaluation so
long training jobs keep advancing. Full 100-point conservation-law curves are
generated afterward from checkpoints with the evaluation scripts.

## Local Paper Commands

Synthetic Markov scaling:

```bash
python scripts/train_causal_ce.py config_name=experiments/markov_scaling/causal_ce logging.enabled=false
python scripts/train_exit.py config_name=experiments/markov_scaling/exit logging.enabled=false
python scripts/train_immse.py config_name=experiments/markov_scaling/immse logging.enabled=false
python scripts/train_bsc.py config_name=experiments/markov_channel_k128/qsc logging.enabled=false
```

To run a specific Markov alphabet size, add `data.alphabet_size=<K>`.

Markov channel comparison at `K=128`:

```bash
python scripts/train_exit.py config_name=experiments/markov_channel_k128/exit logging.enabled=false
python scripts/train_bsc.py config_name=experiments/markov_channel_k128/qsc logging.enabled=false
python scripts/train_immse.py config_name=experiments/markov_channel_k128/immse logging.enabled=false
```

`text8` language-model runs:

```bash
python scripts/train_lm_causal_ce.py config_name=experiments/text8/paper_causal_ce logging.enabled=false
python scripts/train_lm_exit.py config_name=experiments/text8/paper_exit logging.enabled=false
python scripts/train_lm_immse.py config_name=experiments/text8/paper_immse logging.enabled=false
python scripts/train_lm_qsc.py config_name=experiments/text8/paper_qsc logging.enabled=false
```

CIFAR-10 RGB8 UNet image-token runs:

```bash
python scripts/train_img_exit.py config_name=experiments/cifar10_rgb8_unet/paper_exit logging.enabled=false
python scripts/train_img_immse.py config_name=experiments/cifar10_rgb8_unet/paper_immse logging.enabled=false
python scripts/train_img_qsc.py config_name=experiments/cifar10_rgb8_unet/paper_qsc logging.enabled=false
```

The publication language-model configs use the paper effective batch size of
512 sequences. The checked-in `paper_*` configs implement this as
`train.batch_size=64` and `train.grad_accum_steps=8`; lower-memory non-paper
presets may use a different microbatch/accumulation split with the same
effective batch.

## Evaluation And Export Commands

Aggregate language-model summaries:

```bash
python scripts/report_lm_results.py --results-root results/lm
```

Evaluate a saved LM checkpoint:

```bash
python scripts/eval_lm_checkpoints.py --checkpoint results/lm/exit/text8_exit/<run-id>/checkpoints/model_step_0005000.pt --split test --max-batches 16
```

Run the CIFAR-10 image evaluation suite:

```bash
python scripts/eval_cifar_suite.py --run <wandb-run-id-or-path> --sample-count 50000 --conservation-points 100 --step-budgets 25,50,100,200,400,1000,4000
```

Export completed run artifacts into the paper figure-data layout:

```bash
python scripts/export_paper_artifacts.py --paper-root ../paper
```

`scripts/export_paper_artifacts.py` maps completed `results/**/metrics.json`
and curve CSVs to `../paper/shared/figures/data/**`, regenerates the
text8/CIFAR conservation TikZ files, and writes `paper_export_manifest.json`
with source paths.

## Slurm Commands

Synthetic Markov sweeps:

```bash
PROJECT_DIR=$PWD \
ALPHABET_BUNDLES="8,16 32,64 128,256 512" \
sbatch --job-name=exit_markov_paper experiments/sweep_exit_alphabet_h200.sbatch

PROJECT_DIR=$PWD \
ALPHABET_BUNDLES="8,16 32,64 128,256 512" \
sbatch experiments/sweep_causal_ce_alphabet_h200.sbatch

PROJECT_DIR=$PWD \
ALPHABET_BUNDLES="8,16 32,64 128,256 512" \
sbatch --job-name=immse_markov_paper experiments/sweep_default_alphabet_h200.sbatch
```

Dataset bootstrap on Slurm:

```bash
PROJECT_DIR=$(pwd) DATASET=text8 sbatch experiments/bootstrap_lm_datasets.sbatch
PROJECT_DIR=$(pwd) sbatch experiments/bootstrap_cifar10_rgb8_tokens.sbatch
```

Language-model paper runs:

```bash
CONFIG_NAME=experiments/text8/paper_causal_ce sbatch experiments/sweep_lm_causal_ce_h200.sbatch
CONFIG_NAME=experiments/text8/paper_exit sbatch experiments/sweep_lm_exit_h200.sbatch
CONFIG_NAME=experiments/text8/paper_immse sbatch experiments/sweep_lm_immse_h200.sbatch
CONFIG_NAME=experiments/text8/paper_qsc sbatch experiments/sweep_lm_qsc_h200.sbatch
```

CIFAR-10 RGB8 UNet image-token runs:

```bash
CONFIG_NAME=experiments/cifar10_rgb8_unet/paper_exit sbatch experiments/sweep_img_exit_unet_h200.sbatch
CONFIG_NAME=experiments/cifar10_rgb8_unet/paper_immse sbatch experiments/sweep_img_immse_unet_h200.sbatch
CONFIG_NAME=experiments/cifar10_rgb8_unet/paper_qsc sbatch experiments/sweep_img_qsc_unet_h200.sbatch
```

Set `AUTO_TUNE_BATCH=true` on the language-model QSC or image Slurm launchers
only when you intentionally want the launcher to reduce batch sizes for local
hardware constraints.

For 300M-scale LM reruns, keep the canonical paper config and override the
model locally:

```bash
conda run -n gexit torchrun --standalone --nproc_per_node=2 scripts/train_lm_exit.py config_name=experiments/text8/paper_exit model=lm_exit_300m
```

Sanitized server launchers used for paper-scale evaluations are included under
`experiments/server/`:

- `experiments/server/slurm/`: GPU-cluster Slurm wrappers for LM
  conservation-law checkpoint evaluation and CIFAR-10 image eval runs.
- `experiments/server/multigpu/`: multi-GPU VM DDP scripts for 50k image
  generation/evaluation jobs.

These launchers use placeholder paths and generic Slurm account/partition
names. Set `PROJECT_DIR`, checkpoint paths, and scheduler options for your own
environment before running them.

## Outputs

All local training commands write deterministic run outputs under `results/`.

Output roots by experiment family:

- Synthetic causal CE: `results/causal_ce/<experiment-name>/<run-id>/`
- Synthetic EXIT: `results/exit/<experiment-name>/<run-id>/`
- Synthetic I-MMSE: `results/<experiment-name>/<run-id>/`
- LM causal CE: `results/lm/causal_ce/<experiment-name>/<run-id>/`
- LM EXIT: `results/lm/exit/<experiment-name>/<run-id>/`
- LM I-MMSE: `results/lm/immse/<experiment-name>/<run-id>/`
- Image EXIT: `results/img/exit/<experiment-name>/<run-id>/`
- Image I-MMSE: `results/img/immse/<experiment-name>/<run-id>/`
- Image QSC: `results/img/qsc/<experiment-name>/<run-id>/`

Common run artifacts:

- `config.yaml`: resolved config snapshot.
- `metrics.json`: summary metrics and evaluation metadata.
- `train_history.csv`: optimization history.
- `model.pt`: final checkpoint.
- `checkpoints/model_step_*.pt`: intermediate checkpoints.

Experiment-specific artifacts:

- EXIT runs: `exit_curve.csv`, `exit_curve_table.csv`, `exit_curve.png`.
- I-MMSE runs: `immse_curve.csv`, `immse_curve_table.csv`,
  `mmse_curves.png`.
- LM conservation checks: `scripts/eval_lm_conservation.py` compares Monte
  Carlo conservation-law estimates against numerical curve integrals for EXIT,
  QSC, and I-MMSE on `text8`.
- LM checkpoint evaluation: `scripts/eval_lm_checkpoints.py` reloads a saved
  run checkpoint and writes final conservation-law metrics, curves, plots, and
  optional W&B logs.
- Aggregated summaries: `results/lm/lm_summary.csv`,
  `results/lm/lm_summary.tex`.
- Image reconstructions: `reconstructions.png`.
- CIFAR evaluation suite outputs: conservation curves, sample grids, traces,
  FID/IS, and per-schedule generation summaries.
