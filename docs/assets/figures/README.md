# Paper Figure Assets

This directory contains web-sized PNG assets for the GitHub Pages landing page. The CIFAR-10 files are selected paper figure panels, and the Markov/text8 files are rendered summaries for the website.

Source material in the paper workspace:

- CIFAR-10 masked, uniform, and Gaussian generation panels.
- CIFAR-10 masked, uniform, and Gaussian conservation-curve CSV files.
- Markov channel-comparison CSV files in `paper/shared/figures/data/markov_remote/channel_comparison/`.
- text8 BPC values from `paper/shared/tables/exp_text8_results.tex`.
- text8 native-axis conservation-law curve coordinates from `paper/shared/figures/tikz/exp_text8_eval_curves.tex`.
